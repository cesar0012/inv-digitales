# SET 6 — «Bauhaus Geométrico»

## Dirección creativa

formas puras (círculo, cuarto, barra, galón), sombras duras de acento, retícula juguetona.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Composición de formas + tarjeta con sombra dura y punto cónico |
| `02-padres.html` | padres | Bloques con barra superior y retratos en semicírculo |
| `03-ubicacion.html` | ubicacion | Plano con diana pulsante, botón flecha y postal con sombra dura |
| `04-itinerario.html` | itinerario | Escalera de peldaños con chips de formas distintas |
| `05-confirmacion.html` | confirmacion | Anillos concéntricos con satélite orbital y sombra dura |
| `06-detalles.html` | detalles | Obra enmarcada + tarjetas con glifos geométricos |
| `07-countdown.html` | countdown | Dial de cuartos concéntricos con arco de acento |
| `08-padrinos.html` | padrinos | Matriz 2x2 con máscaras de retrato distintas |
| `09-corte.html` | corte | Paleta sólida con filo de acento que barre el cuadro |
| `10-galeria.html` | galeria | Serie con máscaras rotativas y lightbox con sombra dura |
| `11-regalos.html` | regalos | Lista con viñetas de formas y botón con flecha |
| `12-vestimenta.html` | vestimenta | Rueda de discos superpuestos coloreados por JS |
