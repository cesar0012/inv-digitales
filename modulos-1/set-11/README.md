# SET 11 — «Suizo Tipográfico»

## Dirección creativa

retícula estricta, titulares gigantes, reglas finas, cuadrado rojo, fotos en blanco y negro.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Barra superior + titular de dos líneas + columna con regla |
| `02-padres.html` | padres | Tabla de dos celdas A/B con fotos monocromas |
| `03-ubicacion.html` | ubicacion | Tabla de datos + plano con retícula de mira roja |
| `04-itinerario.html` | itinerario | Tabla de programa con numerales y barra roja por fila |
| `05-confirmacion.html` | confirmacion | Manifiesto con barra lateral y RSVP de fondo en contorno |
| `06-detalles.html` | detalles | Tres columnas con índices rojos y glifos geométricos |
| `07-countdown.html` | countdown | Cifras gigantes tabulares + regla con cursor por minuto |
| `08-padrinos.html` | padrinos | Índice 1-4 con retratos 3:4 en grises |
| `09-corte.html` | corte | Puerta con filo rojo que desliza revelando la foto |
| `10-galeria.html` | galeria | Rejilla de 6px con fotos grises numeradas (difference) |
| `11-regalos.html` | regalos | Lista numerada bold con botón que pasa a rojo |
| `12-vestimenta.html` | vestimenta | Fila de muestras tabulares con códigos de color |
