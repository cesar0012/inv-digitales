# SET 8 — «Terracota Mediterránea»

## Dirección creativa

cal y barro: arcos, azulejos, olivos, garabatos dibujados a mano.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Arco de cal con sol giratorio y garabato que se traza |
| `02-padres.html` | padres | Olivos con ramas line-art y subrayados a mano |
| `03-ubicacion.html` | ubicacion | Cenefa de azulejos + mapa en arco con sello punzado |
| `04-itinerario.html` | itinerario | Sendero de tejas con tinta que avanza al scroll |
| `05-confirmacion.html` | confirmacion | Sello de cántaro que se estampa sobre tablero |
| `06-detalles.html` | detalles | Foto en arco + baldosas con cenefa que brotan |
| `07-countdown.html` | countdown | Cántaro con asas cuyo nivel se vacía cada minuto |
| `08-padrinos.html` | padrinos | Faroles de terraza con gancho y encendido escalonado |
| `09-corte.html` | corte | Toldos festoneados que se recogen arriba y abajo |
| `10-galeria.html` | galeria | Macetas de barro con base trapezoidal y lightbox |
| `11-regalos.html` | regalos | Puesto de mercado con toldo a rayas y sellos romanos |
| `12-vestimenta.html` | vestimenta | Azulejos de esmalte con brillo cocido |
