# SET 4 — «Vidrio Esmerilado»

## Dirección creativa

glassmorphism real (backdrop-filter), paneles flotantes translateZ, refracciones prismáticas.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Panel de cristal con prisma en deriva y nombres que salen de foco |
| `02-padres.html` | padres | Paneles flotantes a distinta altura con translateZ |
| `03-ubicacion.html` | ubicacion | Mapa en tarjeta de cristal con brújula giratoria y baliza sonar |
| `04-itinerario.html` | itinerario | Haz de luz que se enciende con el scroll y nodos luminosos |
| `05-confirmacion.html` | confirmacion | Lente de cristal que respira tras el panel RSVP |
| `06-detalles.html` | detalles | Foto esmerilada + fichas que entran en rotateY |
| `07-countdown.html` | countdown | Dial facetado con arco luminoso de segundos |
| `08-padrinos.html` | padrinos | Repisas de cristal con base luminosa |
| `09-corte.html` | corte | Vaho esmerilado que se aparta en dos paneles |
| `10-galeria.html` | galeria | Placas de cristal con destello y lightbox |
| `11-regalos.html` | regalos | Vitrina con prismas y botón con barrido de luz |
