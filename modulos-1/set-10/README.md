# SET 10 — «Marino de Profundidad»

## Dirección creativa

azul abisal, olas en parallax, burbujas JS, máscaras blob orgánicas.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Carta orgánica bajo rayos de luz, burbujas y doble ola |
| `02-padres.html` | padres | Formaciones de coral con contornos blob |
| `03-ubicacion.html` | ubicacion | Cabina de sonar con eco pulsante y pez nadando |
| `04-itinerario.html` | itinerario | Bitácora de descenso por profundidades con cable luminoso |
| `05-confirmacion.html` | confirmacion | Mensaje en la botella que se mece como ola |
| `06-detalles.html` | detalles | Concha blob con perla flotante + tarjetas orgánicas |
| `07-countdown.html` | countdown | Reloj de marea con centro que respira (blob animado) |
| `08-padrinos.html` | padrinos | Cuatro faros con linterna cian por turnos |
| `09-corte.html` | corte | Aguas con borde de ola que se separan del acuario |
| `10-galeria.html` | galeria | Cardumen con máscaras orgánicas y burbujas numeradas |
| `11-regalos.html` | regalos | Cofre con costura luminosa y monedas perla |
| `12-vestimenta.html` | vestimenta | Collar de perlas del litoral coloreadas por JS |
