# SET 7 — «Vitrina de Museo»

## Dirección creativa

pedestales en perspectiva 3D, placas de bronce, focos de sala y textos curatoriales.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Haz de foco que late + vitrina en rotateX + retrato en pedestal |
| `02-padres.html` | padres | Salas con columnas, retratos translateZ y placas de bronce |
| `03-ubicacion.html` | ubicacion | Plano en vitrina de doble fileto con chincheta pulsante |
| `04-itinerario.html` | itinerario | Recorrido de salas en numeración romana |
| `05-confirmacion.html` | confirmacion | Placa dorada con sello giratorio y cuerda de museo |
| `06-detalles.html` | detalles | Obra con marco dorado en 3D + vitrinas con plinth |
| `07-countdown.html` | countdown | Cartas que giran en rotateX al cambiar de valor |
| `08-padrinos.html` | padrinos | Murales 3:4 en marcos dorados colgados alternados |
| `09-corte.html` | corte | Telones de gala que se retiran verticalmente |
| `10-galeria.html` | galeria | Pasillo de lienzos con títulos curatoriales y lightbox |
| `11-regalos.html` | regalos | Boutique curatorial con opciones en romanos |
| `12-vestimenta.html` | vestimenta | Muestras de tela con nombres de pigmento |
