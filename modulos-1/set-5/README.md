# SET 5 — «Neón Editorial»

## Dirección creativa

carbón profundo, glow de neón, tipografía enorme, scanlines y folios de catálogo.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Titular que emerge del desenfoque con glow y subrayado trazado |
| `02-padres.html` | padres | Fichas de catálogo con línea de neón y halo rosa |
| `03-ubicacion.html` | ubicacion | Dos sedes con hora + mapa con marco de neón pulsante |
| `04-itinerario.html` | itinerario | Índice editorial con numerales que se encienden y progreso luminoso |
| `05-confirmacion.html` | confirmacion | Placa con etiqueta RSVP de neón y fecha entre reglas |
| `06-detalles.html` | detalles | Foto con timecode + filas de producción numeradas |
| `07-countdown.html` | countdown | Tablero de neón con letrero EN VIVO latiente |
| `08-padrinos.html` | padrinos | Créditos de reparto en fichas nocturnas |
| `09-corte.html` | corte | Persianas de neón que se abren desde lados opuestos |
| `10-galeria.html` | galeria | Negativos B/N que recuperan color al hover + lightbox |
| `11-regalos.html` | regalos | Checklist de deseados con botón outline que se llena |
| `12-vestimenta.html` | vestimenta | Muestras con marco de neón numeradas |
