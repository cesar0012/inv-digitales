# SET 12 — «Feria Nocturna»

## Dirección creativa

guirnaldas de bombillas, tickets troquelados, banderines, marquesinas y glow ámbar.

Coherencia estética en los 12 módulos; divergencia total respecto a los otros sets. Todos pasan `validateGeneratedModule` (contrato RAG completo) y el gate visual.

## Módulos

| Archivo | Tipo | Diseño |
|---|---|---|
| `01-portada.html` | portada | Ticket de admisión bajo guirnalda de bombillas colgantes |
| `02-padres.html` | padres | Casetas con toldo festoneado y retratos punteados |
| `03-ubicacion.html` | ubicacion | Cuerda de banderines + mapa en cabina con bombilla destello |
| `04-itinerario.html` | itinerario | Marquesina: bombillas que se encienden por parada |
| `05-confirmacion.html` | confirmacion | Ticket troquelado con talón numerado ADMIT ONE |
| `06-detalles.html` | detalles | Foto con bombilla + puestos con toldo y reglamento |
| `07-countdown.html` | countdown | Marquesina con marco de bombillas alternantes |
| `08-padrinos.html` | padrinos | Banderines colgados de la cuerda que se despliegan |
| `09-corte.html` | corte | Cortina de rayas de carpa + estrella que se apaga |
| `10-galeria.html` | galeria | Tiras de photo booth con dos fotos y lightbox |
| `11-regalos.html` | regalos | Caseta de premios con estrellas luminosas |
| `12-vestimenta.html` | vestimenta | Rosetas de staff con picos cónicos y cintas |
